## Salih Eroğul

Ankara’da çalışan bağımsız Shopify geliştiricisiyim. Tema geliştirme, Türkiye’deki altyapılardan
Shopify’a geçiş, hız ve teknik SEO işleri yapıyorum. Ajans değilim; projelerde baştan sona aynı
kişiyle çalışırsınız.

- **Shopify Select Partner**, Eylül 2019’dan beri Shopify Partner
  ([Partner dizini profili](https://www.shopify.com/partners/directory/partner/salih1): 27 Ekim 2026
  itibarıyla 33 değerlendirme, 5,0 puan)
